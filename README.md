# axxell.ai

Il sito pubblicato su axxell.ai (Vercel, file statici, nessuna compilazione).

Il sorgente con i test vive nella bozza di lavoro (`~/axxell-sito-bozza`): le modifiche si fanno lì, si verificano con
`python3 tests/verifica.py` e poi si copiano qui le pagine, `css/`, `js/`, `img/`, `vercel.json`, `robots.txt` e `sitemap.xml`.
